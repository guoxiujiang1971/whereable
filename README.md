Whereable is a comprehensive item management app designed for families and individuals to easily record, track, and manage every item in the home — its location, status, and expiry dates.
Core Features
Item Entry
Multiple input methods: photo recognition, text batch entry (e.g. "wine glass×4, pot" auto-creates multiple items), barcode/QR code scanning, and manual form entry. Each item can record name, location, category, price, expiry date, warranty info, barcode, photos, and notes.
Smart Reminders
Built-in expiry tracking automatically calculates days remaining. Items expiring within 7 days are highlighted on the dashboard, with push notifications sent before expiration. Idle item detection flags items unused for 30+ days.
Family Sharing
Real-time sync across family members via iCloud + CloudKit. Supports public/private two-level permissions — private items visible only to the creator.
Dashboard
Aggregated stats: total items, in-use count, total asset value, unopened boxes, expiring soon (7 days), expired count. Weekly asset report auto-generated and delivered via notification.
Categories & Tags
9 built-in categories (Electronics, Furniture, Clothing, Food, Books, Kitchen, Tools, Toys, Other) with customizable drag-to-reorder. Tag system supports multiple tags per item.
Search
Full-featured search by name, location, category, status, room, and barcode. Search history auto-saved, with quick access to recently added items.
Moving Mode
End-to-end packing workflow: pack → seal → unpack. Create boxes, assign items, seal for transport, then unpack and restore item locations. Each box tracks source room, fragile status, and photos. Includes moving checklist and dashboard.
Spatial Map
Room-level item distribution visualization for a quick overview of where everything is.
Widget
iOS home screen widget displays expiring items in system small and medium sizes. Tap any item to jump directly to its detail page.
iPad Adaptation
NavigationSplitView sidebar layout for quick module switching. Drag-and-drop category reordering.
macOS Catalyst
Native Mac support with multi-window item detail views and keyboard shortcuts (⌘N new item, ⌘1-5 switch modules).
Data Management
Export in JSON, CSV, or PDF formats. Import from JSON/CSV with downloadable template. Auto-sync and backup via iCloud.
Privacy & Security
Data encrypted in iCloud private database; shared data in shared database. Private item marking with strict permission control.
Whereable is for families, movers, food/consumable expiry managers, and anyone who wants every belonging just a tap away.
